# 🏛️ راز هیتلر — Secret Hitler Digital Edition (Official Rules)

یک پیاده‌سازی کامل، آنلاین، چندنفره همزمان (Multiplayer) و واکنش‌گرا از بازی رومیزی محبوب **Secret Hitler** (راز هیتلر)، ساخته‌شده بر اساس قوانین رسمی سال ۱۹۳۲ با طراحی کلاسیک آرشیو اسناد تاریخی و بدون هرگونه ساده‌سازی در منطق بازی.

---

## 🌟 ویژگی‌های برجسته محصول

1. **انطباق ۱۰۰٪ با قوانین رسمی Secret Hitler:**
   - پشتیبانی از ۵ تا ۱۰ بازیکن
   - توزیع دقیق نقش‌ها (لیبرال، فاشیست، هیتلر) و عضویت‌های حزبی
   - دسته قوانین ۱۷ کارتی (۶ کارت لیبرال و ۱۱ کارت فاشیست)
   - منطق کامل انتخابات، دور نوبت صندلی‌ها و منع تصدی متوالی (Term Limits) با استثنای ۵ بازیکن زنده
   - وضعیت آشوب (Chaos) پس از ۳ شکست متوالی دولت
   - جلسات قانون‌گذاری ۳ کارتی رئیس‌جمهور و ۲ کارتی صدراعظم
   - قدرت وتو (Veto Power) پس از تصویب ۵ قانون فاشیست
   - تمام ۴ قدرت اجرایی ریاست‌جمهوری (بررسی عضویت حزبی، انتخابات ویژه، نگاه به قوانین، اعدام)
   - سیستم بررسی خودکار شرایط پیروزی (تصویب قوانین، اعدام هیتلر، صدراعظمی هیتلر در منطقه خطر)

2. **سیستم آنلاین چندنفره و امنیت اطلاعات محرمانه (Server-Authoritative):**
   - ارتباط همزمان مبتنی بر Socket.IO
   - فیلتر هوشمند و رمزنگاری/محرمانگی وضعیت هر بازیکن (هیچ بازیکنی نقش دیگران یا کارتهای مخفی را در بسته دیتای شبکه دریافت نمی‌کند)
   - شناسه نشست امن (`sessionToken`) برای حفظ هویت در قطع و وصل اینترنت
   - جلوگیری از ثبت چندباره اقدامات یا تصاحب صندلی دیگران

3. **تجربه کاربری و طراحی بصری (Mobile-First UI/UX):**
   - هویت بصری منطبق بر اسناد محرمانه، مهرهای اداری و اوراق تاریخی ۱۹۳۲
   - دو زبانه کامل (فارسی راست‌به‌چپ با فونت وزیرمتن و انگلیسی چپ‌به‌راست)
   - پرونده هویت لمس‌محور (Touch-and-Hold Peek) برای جلوگیری از لو رفتن نقش در جمع‌های حضوری
   - طراحی واکنش‌گرا سازگار با گوشی‌های ۳۲۰px، ۳۷۵px، تبلت و دسکتاپ
   - قابلیت نصب به عنوان وب‌اپلیکیشن پیش‌رونده (PWA)
   - سیستم طراحی صدا (Web Audio API Synthesizer) برای کشیدن کارت، چکش ریاست، مهر اسناد و سرود پیروزی با دکمه قطع صدا

4. **ربات‌های آزمایشی (AI Simulation Bots):**
   - امکان پر کردن صندلی‌ها توسط میزبان با ربات‌های هوشمند جهت تست یا بازی تک‌نفره
   - اجرای آزمون‌های شبیه‌سازی ۱۰۰ بازی کامل بدون توقف یا قفل شدن وضعیت

## 🚀 راهنمای نصب و اجرای محلی

### پیش‌نیازها
- **Node.js**: نسخه ۱۸ به بالا
- **npm**: نسخه ۹ به بالا

### ۱. نصب وابستگی‌ها
در پوشه اصلی پروژه دستور زیر را اجرا کنید:
```bash
npm run install:all
```

### ۲. اجرای در حالت توسعه (Development)
برای اجرای همزمان کلاینت و سرور:
- ترمینال ۱ (بک‌اند):
  ```bash
  npm run dev:server
  ```
  سرور روی آدرس `http://localhost:3001` اجرا می‌شود.

- ترمینال ۲ (فرانت‌اند):
  ```bash
  npm run dev:client
  ```
  کلاینت روی آدرس `http://localhost:5173` اجرا شده و درخواست‌ها را به سرور پروکسی می‌کند.

### ۳. ساخت نسخه نهایی و اجرا در حالت انتشار (Production)
```bash
# بیلد کامل سرور و کلاینت
npm run build

# اجرای سرور نهایی
npm start
```
سپس بازی روی `http://localhost:3001` قابل دسترسی است و تمام فایلهای فرانت‌اند و PWA به صورت یکپارچه ارائه می‌شوند.

## 🧪 اجرای آزمون‌های خودکار (Automated Tests)

تمام سناریوهای رسمی بازی و تست‌های همزمان شبکه توسط **Vitest** پوشش داده شده‌اند:
```bash
npm test
```
این آزمون‌ها موارد زیر را اعتبارسنجی می‌کنند:
- تخصیص تصادفی نقش‌ها برای تمام جمعیت‌های ۵ تا ۱۰ نفر
- اطلاعات محرمانه فاشیست‌ها و هیتلر (تفاوت بازی‌های ۵-۶ نفره با ۷-۱۰ نفره)
- تعداد کارت‌های دسته قوانین (۶ لیبرال و ۱۱ فاشیست)
- محدودیت‌های انتخاب صدراعظم و استثنای ۵ بازیکن
- شمارنده انتخابات ناموفق و فعال‌سازی آشوب
- شبیه‌سازی کامل بازی‌های ۵ تا ۱۰ نفره توسط ربات‌ها
- اتصال مجدد (Reconnection) با توکن جلسه و حفظ نقش و دست کارت‌ها

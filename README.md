# 🏛️ راز هیتلر — Secret Hitler Digital Edition (Official Rules)

[![CI Build & Test](https://github.com/Mmd32/secret-hitler/actions/workflows/ci.yml/badge.svg)](https://github.com/Mmd32/secret-hitler/actions/workflows/ci.yml)
[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/Mmd32/secret-hitler)

یک پیاده‌سازی کامل، آنلاین، چندنفره همزمان (Multiplayer) و واکنش‌گرا از بازی رومیزی محبوب **Secret Hitler** (راز هیتلر)، ساخته‌شده بر اساس قوانین رسمی سال ۱۹۳۲ با طراحی کلاسیک آرشیو اسناد تاریخی جمهوری وایمار و بدون هرگونه ساده‌سازی در منطق بازی.

---

## 🌟 ویژگی‌های برجسته محصول

1. **انطباق ۱۰۰٪ با قوانین رسمی Secret Hitler:**
   - پشتیبانی از ۵ تا ۱۰ بازیکن
   - توزیع دقیق نقش‌ها (لیبرال، فاشیست، هیتلر) و عضویت‌های حزبی
   - دسته قوانین ۱۷ کارتی (۶ کارت لیبرال و ۱۱ کارت فاشیست)
   - منطق کامل انتخابات، دور نوبت صندلی‌ها و منع تصدی متوالی (Term Limits) با استثنای ۵ بازیکن زنده
   - وضعیت آشوب (Chaos) پس از ۳ شکست متوالی دولت
   - جلسات قانون‌گذاری ۳ کارتی رئیس‌جمهور و ۲ کارتی صدراعظم
   - قدرت وتو (Veto Power) پس از تصویب ۵ قانون فاشیست
   - تمام ۴ قدرت اجرایی ریاست‌جمهوری (بررسی عضویت حزبی، انتخابات ویژه، نگاه به قوانین، اعدام)
   - سیستم بررسی خودکار شرایط پیروزی (تصویب قوانین، اعدام هیتلر، صدراعظمی هیتلر در منطقه خطر)

2. **حالت آفلاین دورهمی با یک گوشی (Pass & Play):**
   - امکان بازی کامل در مهمانی‌ها بدون نیاز به اینترنت یا سرور
   - پاکت‌های محرمانه دیپلماتیک با مهر و موم فیزیکی و بازگشایی لمسی (Hold-to-Reveal)
   - قابلیت رأی‌گیری مخفی دست‌به‌دست یا اعلام حضوری با شمارش خودکار آرا

3. **سیستم آنلاین چندنفره و امنیت اطلاعات محرمانه (Server-Authoritative):**
   - ارتباط همزمان مبتنی بر Socket.IO
   - فیلتر هوشمند و رمزنگاری/محرمانگی وضعیت هر بازیکن (هیچ بازیکنی نقش دیگران یا کارتهای مخفی را در بسته دیتای شبکه دریافت نمی‌کند)
   - شناسه نشست امن (`sessionToken`) برای حفظ هویت در قطع و وصل اینترنت
   - جلوگیری از ثبت چندباره اقدامات یا تصاحب صندلی دیگران

4. **طراحی بصری فیزیکی و دارایی‌های تأییدشده (Tabletop Asset Kit v1):**
   - صفحات رسمی وکتور مقیاس‌پذیر (SVG) با مختصات دقیق پیکسلی از `asset-manifest.json`
   - صفحات اختصاصی دو ستونه برای موبایل متناسب با عرض گوشی بدون اسکرول افقی
   - تفکیک دو لایه مستقل برای پلاک‌های ریاست‌جمهوری و صدراعظمی بدون تداخل متنی
   - کارت‌های تاریخی تأییدشده و کارت‌های عضویت حزبی و آرای JA! و NEIN!
   - مهره چوبی انتخابات و دسته‌های سه‌بعدی کارت‌های کشیدنی و سوخته

## 🚀 استقرار روی ورسل (Deploy to Vercel)

پروژه به صورت پیش‌فرض شامل فایل پیکربندی [`vercel.json`](./vercel.json) است و به راحتی با یک کلیک روی ورسل مستقر می‌شود:

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/Mmd32/secret-hitler)

### متغیرهای محیطی در ورسل (اختیاری):
- `VITE_SERVER_URL`: آدرس سرور سوکت آنلاین (در صورت راه‌اندازی سرور اختصاصی روی Railway, Render یا Fly.io). در صورت عدم تعریف، حالت آفلاین Pass & Play و استقرار محلی با همان دامنه فعال خواهد بود.

## 💻 راهنمای نصب و اجرای محلی

### پیش‌نیازها
- **Node.js**: نسخه ۱۸ به بالا
- **npm**: نسخه ۹ به بالا

### ۱. نصب وابستگی‌ها
```bash
npm run install:all
```

### ۲. اجرای در حالت توسعه (Development)
- ترمینال ۱ (سرور):
  ```bash
  npm run dev:server
  ```
- ترمینال ۲ (کلاینت):
  ```bash
  npm run dev:client
  ```

### ۳. ساخت نسخه نهایی و اجرا در حالت انتشار (Production)
```bash
npm run build
npm start
```
بازی روی `http://localhost:3001` اجرا می‌شود.
